# Milestone 10 Channel Context and Secondary Morphology Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real-drainage spatial context, optional zones/windows, LPSEC, ordered inter-pool gaps, guarded pool widths, and gated MESH for HydroFragments v1.2 Milestone 10 only.

**Architecture:** `SpatialContext` is sole source of fixed AOI area and real clipped channel length. Zoning and windowing are independent spatial transforms. Metric kernels consume explicit bounded arrays or immutable context and never derive core channel references from wet masks.

**Tech Stack:** Python 3.10+, GeoPandas, Shapely, NumPy, SciPy, scikit-image, pytest.

## Global Constraints

- Real channel contract is `data/fitzroy_kimberley_drainage.gpkg`, SHA-256 `004442d0a65a7eeb51a335dbaa621e281f610080b31e7ae05ee9980a46dc3b3a`.
- Never derive core `L_ref` or Zone 1 from wet-mask morphology.
- No-drainage mode emits only Zones 2, 3, and 4.
- LPSEC is not capped at 100%; braided wetted length may exceed fixed `L_ref`.
- Width is planform morphology only and is suppressed at configured resolution floor.
- MESH remains disabled until real-data LPI correlation is finite and at or below `0.9`.
- NNI and morphology-proxy Zone 1 remain absent.
